# Práctica PHP - Estructuras de Control

## Descripción
Este repositorio contiene 3 problemas básicos en PHP utilizando:
- Formularios
- Operadores matemáticos
- Estructuras de control
- Ciclos

## Problemas

### Problema 1: Suma
Permite sumar dos números ingresados por el usuario.

### Problema 2: Resta
Realiza una resta validando que el primer número sea mayor o igual.

### Problema 3: Multiplicación
Muestra la tabla de multiplicar de un número usando un ciclo for.

## Ejecución
1. Instalar XAMPP o WAMP
2. Colocar la carpeta en:
   htdocs/
3. Abrir en el navegador:
   http://localhost/PracticaPHP
